# Agents.KT Design ver.1

Static landing page concept for [Agents.KT](https://github.com/Deep-CodeAI/Agents.KT), the typed agent runtime for Kotlin and JVM teams.

## Live Site

[Open the GitHub Pages site](https://dimsiq-1.github.io/agents-kt-design-ver-1/)

## What This Contains

- A single-page marketing site in `index.html`
- Brand assets in `assets/`
- Responsive desktop and mobile layout
- GitHub Pages publishing from the repository root

## Design Direction

The page presents Agents.KT as a developer-first JVM runtime with:

- typed `Agent<IN, OUT>` contracts
- compiler-checked composition
- least-privilege tool boundaries
- MCP-native integration
- audit evidence and release-truth positioning

The visual style uses the existing Agents.KT brand palette and logo assets from the upstream repository.

## Local Preview

Open `index.html` directly in a browser, or run a local static server:

```bash
python -m http.server 4177
```

Then visit:

```text
http://127.0.0.1:4177/
```
